# Чтение окружения соседнего пода

## Что проверяем

Два пода на одном узле.

`secret-pod` получает ключ Secret `password` в окружение через `envFrom`. Поле `privileged` у него выключено.

`hostpid-pod` запущен с `hostPID: true`. Поле `privileged` не задано. В его `/proc` видны процессы узла, в том числе процесс соседнего пода. Окружение этого процесса читается из `/proc/<pid>/environ`. Среди переменных оказывается `password`.

## Зачем

Показать, что при `hostPID: true` процесс от uid `0` читает окружение чужих процессов узла с тем же uid, включая значения Secret.
