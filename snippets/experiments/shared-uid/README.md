# Общий каталог и hostUsers

Прогон 22 ноября 2026 на k3s `v1.34.12+k3s1`. Вывод — [output.md](output.md). В показ не входит.

## Что проверяем

Два пода пишут и читают файл режима `0600` в одном каталоге узла. Оба запускаются с `runAsNonRoot: true` и `runAsUser: 1000`.

Пара `writer-host` и `reader-host`: поле `hostUsers` не задано. Каталог на узле — `/var/tmp/kuberconf-shared-host`.

Пара `writer-userns` и `reader-userns`: `hostUsers: false`. Каталог на узле — `/var/tmp/kuberconf-shared-userns`.

Под `shared-uid-prep` создаёт оба каталога и выставляет режим `1777`, чтобы процесс от uid `1000` мог создать файл. Режим каталога к проверке не относится: смотрим файл `0600`.

Общий `hostPath` здесь заменяет общий том двух заданий. Секрета нет.

## Результат

Обе пары читают файл режима `0600`. Ниже для каждой пары отдельно записано, что видно внутри пода и что видно на узле.

Владельца на узле показал под без поля `hostUsers`. Его `/proc/self/uid_map` содержит `0 0 4294967295`: идентификатор внутри совпадает с идентификатором на узле. Под смонтировал оба каталога и выполнил `ls -ln`.

### Пара без `hostUsers`

Каталог на узле — `/var/tmp/kuberconf-shared-host`.

Внутри пода `id` показывает uid `1000`. Файл `/proc/self/uid_map` содержит `0 0 4294967295`: первое число — начало внутри контейнера, второе — начало на узле, третье — длина.

На узле процесс идёт от uid `1000`. Файл `token` принадлежит uid `1000`.

Под `reader-host` читает файл.

### Пара с `hostUsers: false`

Каталог на узле — `/var/tmp/kuberconf-shared-userns`. Точка `/data` смонтирована с флагом `idmapped`.

Внутри пода `id` показывает uid `1000`. Команда `ls` показывает владельца файла `1000`. Файл `/proc/self/uid_map` у подов разный: у `writer-userns` строка `0 4141088768 65536`, у `reader-userns` строка `0 1987117056 65536`.

На узле процесс `sleep` пода `writer-userns` идёт от `4141089768`, пода `reader-userns` — от `1987118056`. Файл `token` принадлежит uid `1000`.

Под `reader-userns` читает файл. Его `runAsUser` равен `1000`. Внутри пода владелец файла — uid `1000`, поэтому режим `0600` открывает файл этому процессу.

## Где запускать

Манифест рассчитан на k3s. На этом прогоне поды с `hostUsers: false` дошли до `Running`: ext4 принимает idmap. На управляемом кластере такой под до `Running` не доходит, snapshotter `overlayfs` idmap не поддерживает.
