# Чтение окружения при общем uid 1000

## Что проверяем

Два пода на одном узле. Секрет `both-uid-1000` создаёт этот каталог. Оба пода запускаются с `runAsNonRoot: true` и `runAsUser: 1000`.

`secret-uid1000` получает ключ Secret `password` в окружение через `envFrom`. Процесс читает файл `/tmp/both-uid-1000`.

`hostpid-uid1000` запущен с `hostPID: true`. Поле `privileged` не задано.

## Результат

Процесс от uid `1000` читает `/proc/<pid>/environ` процесса пода `secret-uid1000`. Среди переменных оказывается `password` этого секрета.
